About

How this site keeps itself current

  • The project timeline is rebuilt every day from the commit history of each repository.
  • The activity log mixes hand-written posts and links with commits and imports from older journals.
  • The keyboard-time chart comes from a small daemon on my computer that publishes hourly totals per project, and nothing more detailed than that.
  • Every page is a single HTML file built from web components, with no framework and no build step.
